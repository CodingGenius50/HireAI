# 🤖 HireAI — Smart Recruitment & Application Tracking System

HireAI is a web-based recruitment platform that connects **Job Seekers and Recruiters**. It allows users to search and apply for jobs, while recruiters can manage companies, jobs, and applicants with AI-assisted CV matching.

## 🌐 Live Demo

- 🖥️ **Frontend:** `YOUR-FRONTEND-URL`
- ⚙️ **Backend API:** https://hireai-backend-byrr.onrender.com
- 📦 **GitHub:** https://github.com/CodingGenius50/HireAI

## ✨ Features

### 👤 Job Seeker
- Register & Login with JWT
- Create profile
- Upload CV
- Search & filter jobs
- Apply for jobs
- Track applications
- AI-assisted CV analysis & job matching

### 🏢 Recruiter
- Recruiter authentication
- Create & manage company
- Post & manage jobs
- View applicants
- Update application status

## 🛠️ Tech Stack

**Frontend:** React, Vite, Tailwind CSS, Axios  
**Backend:** Django, Django REST Framework, JWT  
**Database:** PostgreSQL, Neon  
**AI:** Google Gemini API  
**Deployment:** GitHub & Render

## 🏗️ Architecture

```text
React Frontend
      ↓
Django REST API
      ↓
PostgreSQL / Neon
      ↓
Google Gemini AI
```
